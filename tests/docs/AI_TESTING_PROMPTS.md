# AI-assisted testing prompts

Use these prompts when learning how AI can help with Playwright test design.

## Generate test ideas from a feature

```text
Read this React component and list Playwright test cases for happy path, error states, empty states, accessibility, and mobile behavior. Prefer user-facing locators.
```

## Convert manual QA to Playwright

```text
Convert these manual QA steps into Playwright TypeScript tests using Page Object Model. Add comments explaining each locator, assertion, and wait.
```

## Improve flaky tests

```text
Review this Playwright test for flakiness. Replace fixed timeouts with web-first assertions, role locators, or explicit waits.
```

## Add visual coverage

```text
Suggest stable visual regression snapshots for this dashboard. Avoid highly dynamic dates, animations, or random data where possible.
```
